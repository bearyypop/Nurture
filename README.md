# Nurture

*A fan-made interactive website inspired by Porter Robinson's album Nurture.*

## Project Overview

Nurture is a fan-made website designed as a tribute to Porter Robinson's album *Nurture*, exploring themes of healing, self-discovery, and personal growth. Inspired by the album's emotional vulnerability and visual identity, the website combines interactive elements with a comforting, nature-inspired design. 

## Technologies Used

- **HTML5** — Semantic structure and content organization
- **CSS3** — Styling, layouts, and visual design
- **JavaScript** — Interactive website functionality
- **JSON** — Dynamic song list data
- **Web Storage** — Browser-based data storage
- **Figma** — Wireframing and layout planning
- **Canva** — Color palettes and custom visual effects

## Key Features
- **Dynamic Tracklist** A song list populated using JSON data.
- **Image Carousel** Interactive navigation through visual content
- **Tabbed Content** Organized information into interactive sections
- **Browser Storage** Stores user information locally in the browser
- **Album-inspired Design** A cohesive visual identity inspired by Nurture's artwork and themes. 

## Development Process

I began by defining the websites goals, gathering inspiration through mood boards, and outlining the core functionality. I then created a medium-fidelity wireframe in Figma to establish the content hierarchy, page layout, and interactive sections. 

Using Canva, I developed a cohesive color palette and custom buttons inspired by the album's visual identity. I then built the website using semantic HTML, CSS, and JavaScript, incorporating dynamic JSON content, an image carousel, tabbed sections, and browser storage.

## Challenges & Outcomes

One of the main challenges during development was debugging JavaScript and ensuring that the JSON data loaded correctly. Through troubleshooting and testing, I resolved these issues and successfully implemented the website's interactive features.

The final result was a functional fan-made website that combined a dynamic tracklist, image carousel, tabbed content, and browser storage with a cohesive visual design inspired by Porter Robinson's *Nurture*. 

This project gave me more hands-on experience with JavaScript, especially troubleshooting errors and working with JSON to display content dynamically.
